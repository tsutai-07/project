# Project Instructions

## Project Overview

This is a static Vietnamese restaurant landing page called "Hương Việt".

The project currently uses:
- HTML5
- CSS3
- Vanilla JavaScript

There is currently:
- No backend
- No database
- No framework
- No build system
- No package manager

## Project Structure

- `index.html`: Main page structure and content
- `css/style.css`: Styling, layout, responsive design, animations
- `js/script.js`: Menu data, testimonial data, rendering, and UI interactions

## Development Rules

- Do not introduce a framework unless explicitly requested.
- Do not add a backend unless explicitly requested.
- Do not add external dependencies unless necessary and explicitly discussed.
- Preserve the existing visual identity unless the task asks for a redesign.
- Prefer small, focused changes.
- Do not modify unrelated files.
- Do not remove existing functionality without explaining why.
- Keep the code readable and beginner-friendly.
- Reuse existing CSS variables and styles where appropriate.
- Use semantic HTML where possible.
- Keep JavaScript compatible with modern browsers.

## Before Making Changes

For non-trivial changes:
1. Inspect the relevant files.
2. Explain the proposed approach.
3. Identify which files will be modified.
4. Do not make unrelated changes.

## After Making Changes

After implementing a change:
1. Explain what was changed.
2. List the files that were modified.
3. Check for obvious HTML, CSS, and JavaScript errors.
4. Test the affected functionality when possible.
5. Do not claim that something was tested if it was not actually tested.

## Important Current Issues

The project currently has several known issues:
- The reservation form is not connected to a backend.
- The mobile navigation needs responsive CSS.
- The date form group contains a class-name typo.
- There is a malformed CSS variable reference.
- Some JavaScript function names contain spelling mistakes.
- Responsive behavior needs improvement.

Do not automatically fix these issues unless the user explicitly asks for them.
